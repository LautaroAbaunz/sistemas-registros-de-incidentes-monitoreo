# Organigrama del área técnica (Entrega 3)

![Organigrama del área técnica](img/organigrama-area-tecnica.png)

El área técnica responsable del proyecto se compone de una **Dirección de Técnica**, una **Supervisión de Técnica** y el **Equipo de Desarrollo del Sistema Web** (análisis, diseño, programación, pruebas y mantenimiento).

La **Asesoría Legal** actúa como **staff** de la Supervisión (línea de trazos): asesora sobre protección de datos personales y confidencialidad, ya que el sistema maneja datos de incidentes, ciudadanos, domicilios y registros fílmicos. No tiene autoridad jerárquica sobre el equipo.

- **Línea continua:** autoridad jerárquica formal.
- **Línea de trazos:** relación de asesoramiento (staff).
